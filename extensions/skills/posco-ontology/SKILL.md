# POSCO Ontology MCP

조직·설비·제품·프로세스의 사내 기준 관계에는 연결된 `posco-ontology` MCP만 사용합니다. 도구가 없거나 연결되지 않았으면 상태를 알리고 관계를 추정하지 않습니다. 사용한 개념, 관계와 기준정보 버전을 가능한 범위에서 함께 제시합니다.
