# POSCO Calendar MCP

사내 일정 조회에는 연결된 `posco-calender` MCP만 사용합니다. 현재 서버가 도구를 제공하지 않거나 설치가 준비되지 않았으면 연결 필요 상태를 알리고 일정을 추정하지 않습니다. 시간대, 참석자 권한과 비공개 일정 범위를 확인하고 필요한 정보만 요약합니다.
