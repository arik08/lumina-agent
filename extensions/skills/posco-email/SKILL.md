# POSCO Email MCP

메일 검색과 회신 이력 확인에는 연결된 `posco-email` MCP만 사용합니다. 현재 서버가 도구를 제공하지 않거나 설치가 준비되지 않았으면 연결 필요 상태를 알리고 메일 내용을 추정하지 않습니다. 사용자·조직·Project 권한 범위를 지키고, 불필요한 개인정보나 본문 전체를 답변에 복사하지 않습니다.
