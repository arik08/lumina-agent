# Method Selector

Choose two or three methods whose roles differ: diagnose or frame, generate, then challenge or combine.

| Situation | Primary method | Useful companion | Intended contribution |
|---|---|---|---|
| Improving one objective worsens another | TRIZ | SIT or morphological analysis | Resolve a contradiction without accepting the obvious compromise |
| Existing product, service, or process needs improvement | SCAMPER | SIT | Transform and simplify what already exists |
| The real user need is unclear | Jobs to Be Done | Design Thinking | Reframe the job and discover unmet needs before generating features |
| The stated problem looks like a symptom | Five Whys | First principles | Find actionable causes and rebuild from necessary constraints |
| Many components can be recombined | Morphological analysis | SCAMPER | Explore a broad design space systematically |
| Stakeholders disagree or risks are underexplored | Six Thinking Hats | Premortem-style challenge | Separate facts, intuition, benefits, risks, creativity, and process |
| The current premise may be wrong | Reverse thinking | First principles | Break fixation and expose hidden assumptions |
| Many rough concepts are needed quickly | Rapid ideation | Random or forced connection | Maximize variety before evaluation |
| A new experience or service must be tested | Design Thinking | Jobs to Be Done | Connect user evidence to a cheap prototype |

## Default Combinations

- Product or process improvement: `SCAMPER + SIT + Jobs to Be Done`
- Technical or operational contradiction: `TRIZ + morphological analysis + Five Whys`
- Ambiguous customer problem: `Jobs to Be Done + Design Thinking + SCAMPER`
- Strategy with conflicting perspectives: `Six Thinking Hats + reverse thinking + morphological analysis`

Use a single method only when the user explicitly requests it or the task is very narrow. Use more than three only for a facilitated workshop with enough time and participants.
