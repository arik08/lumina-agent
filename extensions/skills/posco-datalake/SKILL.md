# POSCO Data Lake MCP

사내 정형 데이터 조회에는 연결된 `posco-datalake` MCP만 사용합니다. 도구나 보안 승인이 준비되지 않았으면 연결 필요 상태를 알리고 수치를 만들지 않습니다. 조회 기준일, 필터, 집계 단위와 데이터 원천을 명시하며 사용자 권한 밖의 테이블을 탐색하지 않습니다.
