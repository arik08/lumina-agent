# 로그인 개발 계정 아이콘 설계

## 목적

개발 환경의 로그인 화면에서 `개발 계정 admin@posco.com 채우기` 기능은 유지하되, 개발 편의 기능이 일반 로그인 안내보다 두드러지지 않게 한다.

## UI 설계

- 현재 텍스트 버튼을 작은 `UserPlus` 아이콘 버튼으로 교체한다.
- 버튼은 로그인 폼 상단 오른쪽에 유지하여 기존 입력 흐름과 레이아웃을 바꾸지 않는다.
- 마우스 호버와 키보드 포커스 시 `개발 계정 admin@posco.com 채우기` 툴팁을 표시한다.
- 아이콘 버튼에는 같은 문구의 접근성 이름을 제공하고 아이콘 자체는 보조 기술에서 숨긴다.
- 툴팁은 입력 영역과 겹치지 않도록 아이콘 위쪽에 표시하며, 짧은 지연 없이 빠르게 나타난다.

## 동작

- 버튼을 누르면 기존과 동일하게 아이디를 `admin`, 주소를 `posco.com`으로 채우고 비밀번호 입력란으로 포커스를 옮긴다.
- 제출 중에는 버튼을 비활성화한다.
- `import.meta.env.DEV` 조건을 유지하여 개발 빌드에서만 노출한다.

## 검증

- 정적 UI 검증으로 텍스트가 상시 노출되지 않고 접근성 이름과 툴팁 문구가 존재하는지 확인한다.
- Frontend typecheck와 production build를 실행한다.
- Codex 앱의 실제 화면에서 아이콘 크기·정렬, 호버 툴팁, 클릭 후 자동 입력, 키보드 포커스, 텍스트 겹침·잘림과 콘솔 오류를 확인한다.

## 범위 제외

- Bootstrap 계정과 비밀번호 정책은 변경하지 않는다.
- 로그인 폼의 나머지 레이아웃과 인증 동작은 변경하지 않는다.
